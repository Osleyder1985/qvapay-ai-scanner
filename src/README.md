# Source Code

Contendrá el código fuente del producto y de los componentes que evolucionen desde los prototipos hacia software mantenible.

## Backend actual

El backend del dashboard P2P utiliza Node.js + TypeScript. Se mantiene un diseño modular para permitir incorporar posteriormente collectors, persistencia, analytics y workers sin convertirlos prematuramente en microservicios.

Python queda reservado para componentes de analytics/ML/AI cuando aporten una ventaja técnica real.
