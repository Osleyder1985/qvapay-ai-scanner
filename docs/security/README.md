# Security documentation

This directory defines the security model and the active risk treatment for QvaPay AI Scanner.

- `dashboard-trust-boundary.md` — current local-only deployment boundary.
- `threat-model.md` — assets, trust boundaries, threats, STRIDE mapping and required controls.
- `risk-register.md` — active risks, mitigations, residual risk and release gates.

Security-sensitive architecture changes must update the relevant security documentation in the same change.
