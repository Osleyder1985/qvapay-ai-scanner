# Normas y referencias

## ISO/IEC/IEEE 12207
Se utiliza como referencia para organizar procesos del ciclo de vida del software.

## ISO/IEC/IEEE 29148
Se utiliza como referencia para ingeniería, especificación y trazabilidad de requisitos.

## ISO/IEC 25010
Se utiliza como referencia para características de calidad del producto: adecuación funcional, rendimiento, compatibilidad, usabilidad, fiabilidad, seguridad, mantenibilidad y portabilidad.

## ISO/IEC 27001 e ISO/IEC 27002
Se utilizan como referencias para gestión y controles de seguridad de la información.

## Nota
El uso de estas referencias no constituye una declaración de conformidad, auditoría o certificación.
