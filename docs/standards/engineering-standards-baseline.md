## Interpretación

La matriz identifica referencias utilizadas para orientar ingeniería y evidencia interna. El proyecto puede estar alineado con prácticas o controles concretos sin ser conforme o certificado frente a una norma.

No se debe escribir “certificado”, “conforme con ISO” o equivalente salvo que exista una evaluación formal y evidencia externa independiente.

No se copia texto protegido de las normas. Sólo se registra la referencia, su estado y el vínculo con artefactos propios.
