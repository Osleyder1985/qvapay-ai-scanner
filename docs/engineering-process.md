# Proceso de ingeniería

El proyecto seguirá un ciclo incremental: investigación, requisitos, diseño, implementación, verificación, evaluación y documentación.

Cada cambio relevante debe mantener trazabilidad hacia una necesidad o requisito y hacia evidencia de verificación cuando sea aplicable.

El proceso toma como referencia ISO/IEC/IEEE 12207 e ISO/IEC/IEEE 29148.
