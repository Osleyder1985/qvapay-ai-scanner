# QvaPay AI Scanner

## Propósito

Este repositorio contiene la ingeniería, investigación, documentación, prototipos y software relacionados con el ecosistema QvaPay AI Scanner.

El proyecto se desarrolla de forma incremental y basada en evidencia, priorizando las capacidades oficiales de QvaPay, la automatización, el análisis de datos, la inteligencia artificial y la creación de oportunidades de negocio técnicamente y económicamente verificables.

## Principios de ingeniería

- Trazabilidad entre necesidades, requisitos, decisiones, implementación y pruebas.
- Evidencia antes de asumir capacidades o resultados económicos.
- Seguridad y protección de credenciales desde el diseño.
- Automatización únicamente cuando las reglas de QvaPay y los controles de riesgo lo permitan.
- Preferencia por tecnologías gratuitas o de coste cero durante la investigación y prototipado.
- Evolución incremental mediante cambios pequeños, revisables y reproducibles.

## Marco de referencia

La organización del proyecto toma como referencia ISO/IEC/IEEE 12207 para procesos del ciclo de vida del software, ISO/IEC/IEEE 29148 para ingeniería de requisitos, ISO/IEC 25010 para calidad del producto y ISO/IEC 27001/27002 como referencia para gestión y controles de seguridad de la información.

Estas normas se utilizan como marco de buenas prácticas; no se declara conformidad o certificación del proyecto salvo que se realice una evaluación formal.

## Estructura

- `docs/`: documentación controlada del proyecto.
- `requirements/`: necesidades y requisitos.
- `architecture/`: arquitectura y decisiones técnicas.
- `research/`: investigación y evidencia.
- `src/`: código fuente.
- `tests/`: pruebas automatizadas y evidencia de verificación.
- `experiments/`: experimentos controlados.
- `tools/`: herramientas auxiliares.
- `config/`: configuraciones no sensibles y plantillas.
- `scripts/`: automatizaciones reproducibles.
- `evidence/`: evidencias de investigación y validación.

## Idioma

Los nombres de archivos, directorios, ramas, etiquetas, Issues y Pull Requests se mantienen en inglés. El contenido documental y las discusiones se redactan en español.

## Estado

El proyecto se encuentra en fase de saneamiento y validación: la baseline de ingeniería ya está implementada y el checkpoint pendiente es la aceptación contra QvaPay real antes de ampliar automatización financiera.
